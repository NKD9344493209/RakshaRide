🧠 How RakshaRide decides: crash vs everything else

The classifier never judges an impact alone — it judges the story around it. Three gates must all agree before the countdown even starts.

Gate 1 — Riding context

Armed only when GPS shows sustained vehicle speed (>15 km/h) with two-wheeler vibration texture. A phone dropped in your kitchen, or a rollercoaster (no road-matched GPS trajectory, park geofence, repetitive smooth high-G pattern) never arms the detector.

Gate 2 — Impact signature

features = [peakG, spikeCount, freefall_ms, rotationEnergy, ΔGPS_speed, duration]
EventSignatureVerdict
Phone dropfree-fall ~0g → ONE clean spike → low rotation → pickup motion in secondsREJECT
Potholesingle vertical spike, GPS speed continuesREJECT
Rollercoasterrepetitive smooth G-waves, no road context, motion continuesREJECT
Crash40→0 km/h deceleration + multiple chaotic spikes + 3-axis tumblingESCALATE

Gate 3 — Post-impact stillness

The decisive evidence: after a real crash, GPS speed stays 0 and the phone shows no human motion. Only then the siren + 15 s cancel countdown fires — a conscious rider cancels with one tap (which becomes a labelled training sample); silence is confirmation.

Severity model → response

severity = 35·(pre-speed/60) + 30·(peakG/16g) + 20·rotationEnergy + 15·stillness → CRITICAL / SEVERE / MODERATE

Severity drives everything downstream: which ambulance, which trauma level hospital gets pre-alerted, and queue position in the 108 command center.

Production mapping

  • Phone: background service (Android foreground service / iOS motion API), on-device TFLite classifier trained on team-collected labelled rides, drops, and crash-dummy tests.
  • Alerts: structured payload over data; SMS fallback when no internet (store-and-forward works where data fails on highways).
  • Command center: FastAPI + PostGIS, GVK-EMRI 108 integration, hospital HMIS pre-alert, family live-tracking links.
  • This prototype: the same pipeline in-browser — real DeviceMotion sensors on a phone, synthetic signatures on a laptop, identical decision code.
